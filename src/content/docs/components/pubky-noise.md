---
title: "Pubky Noise"
---

[Pubky Noise](https://github.com/pubky/pubky-noise) is a library under development for encrypted communication through [Homeservers](/components/homeserver/). It lets applications exchange encrypted messages through hosted storage without requiring both participants to be online together.

It is relevant to developers building private communication between Pubky identities, including the [Paykit](/components/paykit/) work. It is a building block for applications, rather than a standalone messaging app.

See the [Pubky Noise README](https://github.com/pubky/pubky-noise/blob/master/README.md) for its transport and session model, and the [Rust API reference](https://docs.rs/pubky-noise/latest/pubky_noise/) for the library interface.
