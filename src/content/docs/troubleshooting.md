---
title: "Troubleshooting Guide"
---

Start with the problem you are seeing, then follow the guide maintained with the relevant project:

| Problem | Start here |
| --- | --- |
| An app cannot sign in, find a Homeserver, or read/write data | [SDK documentation](/explore/pubky-protocol/sdk/) and [Homeserver issues](https://github.com/pubky/pubky-homeserver/issues) |
| Homeserver installation or public deployment | [Install Guide](https://github.com/pubky/pubky-homeserver/blob/main/docs/INSTALL.md) and [Deployment Guide](https://github.com/pubky/pubky-homeserver/blob/main/docs/DEPLOY.md) |
| The tutorial's local stack does not start | [Pubky Docker README](https://github.com/pubky/pubky-docker#readme) |
| Ring cannot open or approve an app request | [Pubky Ring issues](https://github.com/pubky/pubky-ring/issues) |
| A pubky.app screen or interaction does not work | [pubky.app issues](https://github.com/pubky/pubky-app/issues) |
| Published data is missing from feeds or search | [Nexus documentation](/explore/pubky-apps/indexing-and-aggregation/pubky-nexus/) |

Search existing issues before reporting a problem. Include the component and version, platform, reproduction steps, expected result, and the error message. Remove recovery phrases, private keys, tokens, session credentials, and personal data from logs and screenshots.

For general help, use the [community channels](/resources/#community-channels). Report security vulnerabilities through the [Pubky Security Policy](https://github.com/pubky/.github/blob/main/SECURITY.md).
